## 本地生产包对比

使用相同机器、Chrome 157、Lighthouse 13.6 手机模拟节流及冷缓存。修改前为 Git HEAD 构建，并带入工作区已有的三篇文章变更；修改后为当前生产构建。两份构建使用相同的本地 gzip 静态服务，均屏蔽 Google 统计和 Waline 后端请求，避免外部服务波动及写入阅读次数。动态页每个版本测量 3 次，表中为中位数；首页每个版本测量 1 次。

| 指标 | 修改前 | 修改后 |
| --- | ---: | ---: |
| 动态页手机性能分 | 83 | 100 |
| 动态页 LCP | 4.79 秒 | 0.75 秒 |
| 动态页总加载量（Lighthouse total-byte-weight） | 571,956 bytes | 234,739 bytes |
| 动态页脚本传输量 | 390,084 bytes | 147,562 bytes |
| 首页手机性能分 | 96 | 96 |
| 首页 LCP | 2.84 秒 | 2.73 秒 |
| 首页总加载量 | 345,029 bytes | 250,232 bytes |

动态页总加载量减少 59.0%，脚本传输量减少 62.2%。关闭动态正文的淡入动画后，静态内容可以立即绘制，禁用 JavaScript 时正文同样可见。这些是本地对比结果，不代表线上已部署或开启真实 GA 后的成绩。

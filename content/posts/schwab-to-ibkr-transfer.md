> 现金用 ACH 推款（$0，≤1 天）；持仓用**部分** ACATS（$0，4–8 个工作日，不卖出、不产税、不关户）。
> **整户 ACATS 千万别选**——嘉信收 $50，而且会清空并关掉嘉信账户。

---

## 一、四条路怎么选


| 方式 | 嘉信费用 | IBKR 费用 | 关户 | 到账 | 适用 |
| ------------ | ------- | ------- | ---- | ------- | ---- |
| **ACH 推款** | **$0** | $0 | 否 | ≤1 工作日 | ✅ 现金 |
| **部分 ACATS** | **$0** | $0 | 否 | 4–8 工作日 | ✅ 持仓 |
| 整户 ACATS | **$50** | $0 | ⚠️ 是 | 4–8 工作日 | ❌ |
| 银行电汇 | 线上 $0 | $0 | 否 | 当天 | 大额急用 |


两个前提：

1. **IBKR 两头都不收 ACATS 费，但也不报销**任何一方的转户费。所以省钱的唯一办法是让嘉信那边收 $0——即只走**部分**转移。
2. **ACATS 是原样搬，不产生卖出行为**，所以不触发资本利得。这正是它比"卖掉→转现金→重买"强的地方：不产税、不踏空。

### ACH 和 ACATS 到底差在哪

一句话：**ACH 是"转账"，ACATS 是"过户"。**


|  | ACH 推款 | 部分 ACATS |
| --------- | ------------------------------- | ----------------------------- |
| **搬什么** | 只能搬**现金** | 搬**持仓**（股/ETF/期权/债/基金），可顺带带现金 |
| **走哪条网** | 银行清算网（把券商账户当银行账户用） | NSCC/DTCC 的券商间过户系统，**不碰银行系统** |
| **要不要卖出** | 前提就是已经是现金；有持仓必须**先卖** → 产税 + 踏空 | **原样搬，不卖出**，不产税、不断仓 |
| **谁发起** | 嘉信端（你在嘉信点转出） | IBKR 端（接收方"拉"，嘉信只负责确认） |
| **速度** | ≤1 工作日 | 4–8 工作日 |
| **过程中** | 无冻结 | 持仓在**两边都冻结**，不能交易 |
| **成本价** | 无此概念 | 延迟 ~15 天才补齐 |


**为什么不能只用一条路**：ACH 搬不了股票——它只认钱，系统里根本没有"股票"这个字段；ACATS 虽然也能带现金，但慢一周，纯现金用它是杀鸡用牛刀。

```
现金  ──ACH──▶    1 天到，$0
持仓  ──ACATS──▶  一周到，$0，不产税
```

**最关键的那条差别**：持仓有浮盈时，走"卖掉 → ACH 转现金 → 重买"，卖出那一刻就是**应税事件**，还要承担卖出到买入之间的踏空风险。ACATS 的全部价值就在于绕开这一步——股票只是从嘉信的账本挪到 IBKR 的账本，**市场上没有发生任何一笔交易**。

## 二、现金：ACH 推款

嘉信的 ACH（MoneyLink）转券商账户 $0、最低 $1，**和有没有借记卡、支票账户无关**，券商账户本身就能转。

用"嘉信端推款"只需要 IBKR 的收款号码，不需要你自己的嘉信银行号码。

### 步骤

**① 在 IBKR 取号**
Transfer & Pay → Transfer Funds → Deposit Funds → 币种 USD → **Direct ACH Transfer from your Bank** → 记下 **Routing Number**（9 位）和 **虚拟账号 VAN**（12 位数字）。

> ⚠️ VAN ≠ 你的 IBKR 账户号（U 开头那个）。填错是最常见的失败原因。
> ⚠️ VAN 是双向可用的（能被扣款），**别公开、别发给陌生人**。

**② 在嘉信加外部账户**
Move Money → External Accounts → 添加外部银行账户：

- 持有人 → **Yes**（同名第一方转账最快）
- Routing number → IBKR 给的路由号
- Account number → **VAN**
- Account type → **Checking**
- 显示 **UMB Bank** 是正常的，那是 IBKR 的合作托管行

**③ 验证**
嘉信打一笔几美分测试存款（1–3 工作日），到 IBKR 的 Activity / Transactions 里查金额，回嘉信填回去确认。

**④ 转账**
Move Money → Transfer Funds → 源=嘉信，目标=IBKR → 金额 → 提交，约 1–2 工作日到账。

> **推款 vs 拉款**：推款（VAN 方式）到账即可交易，提现锁 3 个工作日；IBKR 端"拉款"要 4 个工作日才能交易，提到别的银行要锁 44 个工作日。**选推款**。

## 三、持仓：部分 ACATS

ACATS 由**接收方发起**，所以全程在 IBKR 操作，嘉信只负责确认。

### 步骤

Transfer & Pay → **Transfer Positions** → **Incoming** → 地区选 US → 方式选 **ACATS** →

1. 填嘉信信息：券商、**账户号**、**账户全称**、**账户类型**、**税号**
2. "Transfer all assets?" → 选 **No**（这一步就是"部分 vs 整户"的分水岭，选 Yes 就是 $50 + 关户）
3. **Add Asset** 逐个填代码和股数，持仓多可用 **Upload CSV**
4. 签名提交

> 坑：IBKR **不能同时"保存券商信息"和"执行转账"**。如果勾了保存，这一次只是建档，要回到 Transfer Positions 再发起一次才真正转。

### 转不过去的东西（提前处理，否则被 reject）


| 资产 | 原因 | 怎么办 |
| ---------------------------- | ------------------------ | ----------------------------------- |
| **碎股 / 零股**（嘉信 Stock Slices） | ACATS 只走整股 | 先卖成整数股；剩下的碎股由嘉信卖出，现金**另行返还，可能拖数十天** |
| **嘉信自家基金**（SWVXX 等货币基金） | FINRA 11870：发出方自有产品默认不可转 | 先在嘉信赎回成现金，走 ACH |
| **未交收持仓**（刚买的） | 未交收不能转 | 留出 T+1 |
| **期权**（到期周） | ACATS 到期周不处理期权 | 避开 expiration week |


**账户全称、账户类型、税号必须与嘉信完全一致**（含中间名、拼写），任一不符直接被拒。

### 时间与限制

- **4–8 个工作日**：嘉信 1 个工作日内确认，之后 3 个工作日内完成交收，加上审核期
- 转移期间持仓在**两边都冻结**，不能交易。要调仓请在提交前做完
- 到 IBKR 后**可立即交易**，但转入资产的**提现/再转出有限制期**（IBKR 标注最长 30 天）
- **成本价（cost basis）不随 ACATS 走**，由 DTCC 的 CBRS 单独传，通常转完 **~15 天**后才补齐

### 关于成本价

**成本价 = 你当初买入这笔资产花的钱**，是算资本利得税的基准线：

```
$400 买入 SPY，现涨到 $600
成本价 = $400  →  应税收益 = $600 − $400 = $200
```

ACATS 搬的是**股数**，成本价走另一套系统、慢 ~15 天。这中间 IBKR 里成本价会显示 **$0 或空白**，界面上那笔 SPY 就成了"盈利 $600"。**这时候拿 IBKR 的数字报税，等于把 $600 全当收益申报，白缴一大笔。**

三点要注意：

1. **等它补齐再看盈亏**。转完两周内 IBKR 显示的盈亏一律不信。
2. **老仓位可能永远补不齐**。2011 年前买入的属于 non-covered securities，券商没有法定义务传成本价。这种要**自己在 IBKR 手动填**。
3. **转之前先把嘉信的历史对账单全部下载存档**。成本价补不齐时这是唯一凭证，账户一关记录就难拿了。

> 如果你不是美国税务居民，美股资本利得本身不向美国征税，但成本价仍影响居住国的申报口径和 IBKR 界面的盈亏可读性。

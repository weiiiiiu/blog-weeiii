## 一个常见的误解

「我用的是美国盈透，不在 CRS 里，所以没事。」

前半句对，后半句错。而且错在两个不同的层面：

1. **券商不在 CRS 里，不代表你不在。** 你从券商出金到哪张卡上，那张卡可能就在。
2. **信息不交换，不代表不用交税。** 纳税义务自应税行为发生之日起就成立，跟税务局知不知道无关。

这篇把两件事拆开算：**CRS 到底报什么数**，以及**税到底按什么数算**。这两个数不是一回事，能差出一个数量级。

## 一、CRS 在中国的实际状态


| 时间 | 事件 |
| ---------- | ------------------------------------------- |
| 2014-09 | 我国在 G20 层面承诺实施「标准」 |
| 2016-02 | 《多边税收征管互助公约》对我国生效 |
| 2017-07-01 | 《非居民金融账户涉税信息尽职调查管理办法》施行（六部委 2017 年第 14 号公告） |
| 2018-09 | 总局首次与境外税务主管当局交换信息 |
| 至今 | 交换伙伴 **106 个**，覆盖香港、新加坡、开曼等全部主要金融中心 |


信息的流向是：**境外金融机构 → 该国税务当局 → 国家税务总局**。境外开户时签的那份「税收居民身份声明文件」

## 二、报什么：按账户类型，逐条对号

《管理办法》第三十五条规定了报送字段。**不同账户类型报的东西完全不同**，这是后面所有推论的基础：


| 账户类型 | 报送内容 |
| -------------- | -------------------------------------------- |
| 通用（所有账户） | 姓名、现居地址、税收居民国、TIN、出生地、出生日期、账号、**公历年度末余额或净值** |
| **存款账户(HSBC)** | 年度内收到或计入该账户的**利息总额** |
| **托管账户（IBKR）** | 利息总额、股息总额，以及**因销售或赎回金融资产而收到的收入总额** |
| 其他账户 | 年度内收入总额，包括赎回款项总额 |


两个容易被忽略的细节：

- **存款账户不报流水。** 往港卡里转了几笔、每笔多少、花掉多少，CRS 都不报。只报 12 月 31 日那个余额，加全年利息。
- **托管账户报的是 gross proceeds。** 「销售金融资产的收入总额」是每笔卖出的成交金额直接相加，**不减成本、不减亏损**。

第二条是本文的核心。它意味着 CRS 交换过来的数字**根本判断不了你有没有赚钱**。

## 三、账户分别落在哪一格

美国从未加入 CRS。它只有 FATCA，而 FATCA 对中国是**单向**的——中美只到「实质性达成共识（Agreement in Substance）」阶段，从未签署正式 IGA，美国也从未向中国回传过任何中国居民在美账户信息。


| 账户 | 主体 | CRS |
| --------------------- | ----------------------------------------------------------- | ------ |
| 盈透 | **Interactive Brokers LLC**（美国，账户号 **U** 开头） | 不参与 |
| 嘉信 | **Charles Schwab & Co., Inc.**（international.schwab.com 入口） | 不参与 |
| 盈透香港 / 新加坡 / 爱尔兰 / 澳洲 | 对应当地主体 | **参与** |
| 富途、老虎等港资/新加坡券商 | 香港 / 新西兰等 | **参与** |
| 中银香港、汇丰香港 | 香港 | **参与** |


**自查方法**：IBKR → 报表与税务 → 活动报表，看抬头的法律主体名称。

## 四、四个口子，第一个就是港卡

这是本文最想说的一节。

### 1. 港卡（最确定的一个）

[从 IBKR 出金到港卡](/posts/ibkr-usd-to-hk-card)这条路径本身没问题，但要意识到：**港卡是香港金融机构开立的、由内地税收居民持有的账户**——教科书式的 CRS 报送对象。香港税务局每年把你的年末余额和利息交换给国家税务总局。

所以格局是：**券商那头封死了，银行这头是敞开的。** 总局看不到你 IBKR 的持仓和盈亏，但能看到你港卡余额，以及这个余额跟你的申报收入对不对得上。多地税务机关公布的做法正是「利用大数据比对纳税人跨境资金流动、金融账户涉税信息以及出入境记录，识别疑点纳税人」。

### 2. IBKR 的 F 结尾子账户

如果开通了**非美指数期权**（恒指、A50）、**贵金属现货**（XAUUSD）、**CFD**，IBKR 会自动挂一个 **F 结尾的英国子账户**——英国是 CRS 辖区。要关得单独发工单给客服，关了这几个产品就用不了。

### 3. 中美税收协定第 26 条（情报交换）

不是自动的，是**专项请求**。中国税务机关有合理理由怀疑时，可依协定向美方请求调取特定账户信息。触发门槛高，但通道存在。

### 4. 外管局与税务的数据联动

大额购汇、跨境汇入、频繁出入金都在监测范围内。两个部门已在共同建立日常信息交换机制。

## 五、纳税义务：跟信息交换是两件事


| 项目 | 规则 |
| ----- | ---------------------------------- |
| 谁要报 | 境内有**住所**，或一个纳税年度居住累计满 **183 天** |
| 报什么 | 境外股票转让所得、股息红利、利息（财税 2020 年第 3 号公告） |
| 税率 | **20%** 比例税率，不与境内综合所得合并，单独计算 |
| 申报期 | 取得所得的**次年 3 月 1 日 – 6 月 30 日** |
| 券商代扣 | **没有**。境外券商不代扣代缴，全靠自行申报 |
| A 股豁免 | **不适用境外股票**。A 股转让暂免个税，港美股不免 |


关于「住所」——这不是指房产，是《实施条例》第二条的法定概念：**因户籍、家庭、经济利益关系而在中国境内习惯性居住**。所以保留内地户籍、家人在内地、主要资产在内地，大概率仍是内地税收居民，哪怕一年在境内待不满 183 天。

## 六、完整算例：同一年，两个数

假设 2026 年做了这些操作。


| 标的 | 买入 | 卖出 | 佣金 | 已实现盈亏 |
| ---- | ----------- | -------------------- | --- | ------------ |
| NVDA | 2 月 $50,000 | 5 月 $68,000 | $4 | **+$17,996** |
| TSLA | 3 月 $30,000 | 6 月 $24,000 | $4 | **−$6,004** |
| SPY | 1 月 $80,000 | 12 月 $92,000 | $4 | **+$11,996** |
| AAPL | 8 月 $40,000 | **没卖**（年末市值 $35,000） | — | **0** |


另：全年股息 $1,500，IRS 按中美协定预扣 10% = $150。年末提 $60,000 到中银香港，全年活期利息 $480。

### 第 1 步 · 财产转让所得

**只算已实现的。** AAPL 浮亏 $5,000 不进税基——没卖就不存在。

```
已实现盈亏 = 17,996 − 6,004 + 11,996 = +$23,988
```

**汇率口径**：《个人所得税法实施条例》第三十二条，年度汇算清缴按**上一纳税年度最后一日**人民币汇率中间价折算，即所得年度的 12 月 31 日。下面假设为 7.10：

```
应纳税所得额 = 23,988 × 7.10 = RMB 170,315
应纳税额     = 170,315 × 20% = RMB 34,063
```

### 第 2 步 · 股息红利所得

```
收入   = 1,500 × 7.10 = RMB 10,650
应纳税 = 10,650 × 20% = RMB 2,130
```

### 第 3 步 · 境外税额抵免（分国计算）

美国这一国的抵免限额 = 34,063 + 2,130 = **RMB 36,193**
在美国实缴 = $150 × 7.10 = **RMB 1,065**，低于限额，可全额抵免。

超过限额的部分可在以后 **5 个纳税年度**内结转抵免（3 号公告第六条）。

### 第 4 步 · 港卡利息（最容易漏）

境外利息所得同样按 20% 征。香港对个人存款利息不征税，**所以没有可抵免的境外税额，全额落在国内**：

```
480 × 7.10 × 20% = RMB 682
```

### 汇总


| 项目 | 金额（RMB） |
| --------- | ---------- |
| 财产转让所得应纳税 | 34,063 |
| 股息红利应纳税 | 2,130 |
| 港卡利息应纳税 | 682 |
| 减：境外已缴可抵免 | −1,065 |
| **合计应补** | **35,810** |


### 同一年，CRS 报出去的是什么

**你的实际情况（IBKR 美国主体 + 港卡）**，总局收到的只有一行：

> 中银香港，存款账户，年末余额 USD 60,000，年度利息 USD 480

持仓、交易、盈亏，一个字都没有。

**但假如换成港资券商**，报出去的是：

```
出售金融资产收入总额 = 68,000 + 24,000 + 92,000 = $184,000 ≈ RMB 130.6 万
股息总额             = $1,500
年末账户净值         ≈ $95,000
```


|  | 金额（RMB） |
| ------------------------ | ------------- |
| 税务局屏幕上的数（gross proceeds） | **1,306,400** |
| 真实税基（已实现盈亏） | **170,315** |
| **倍数** | **7.7×** |


这就是为什么执法方式是「提醒你自查」而不是直接开单——**CRS 交换来的信息判断不了账户是否盈利**，得纳税人自己算、自己报。

第一财经报道过一个北京的例子：某位纳税人港股流水几千万人民币，2023 年实际是亏的，接到电话后提交了券商月结单加一份手写说明，最后不需要补税，也没有滞纳金。

## 七、这个算例里能优化的一处

上面 AAPL 的浮亏 $5,000，如果 **12 月 31 日前卖掉**：

```
已实现盈亏 = 23,988 − 5,000 = $18,988
应纳税额   = 18,988 × 7.10 × 20% = RMB 26,963
```

**少交 RMB 7,100**（= 5,000 × 7.10 × 20%）。

原理是「同年可抵、跨年不可抵」——亏损是一张年底过期的优惠券。这一条以及批次匹配方法怎么配合，[另一篇](/posts/ibkr-tax-lot-matching)里有更完整的推演，这里不重复。

## 八、申报要准备的材料


| 材料 | 从哪拿 |
| --------- | --------------------------------------- |
| 年度已实现盈亏明细 | IBKR → 报表与税务 → 年度报表（Realized Summary） |
| 佣金与费用汇总 | 同上，Fees 部分 |
| 股息完税凭证 | **Form 1042-S**（每年 3 月出）。**没有完税凭证不予抵免** |
| 港卡利息 | 中银 / 汇丰年度结单 |
| 汇率 | 所得年度 12 月 31 日人民币汇率中间价 |


申报入口：个税 APP →「境外所得申报」，或自然人电子税务局网页端。填《个人所得税年度自行纳税申报表（B 表）》，附报《境外所得个人所得税抵免明细表》。

申报地：境内任职受雇单位所在地；没有的，向户籍所在地或经常居住地主管税务机关申报

## 小结


| 问题 | 答案 |
| ------------ | -------------------------------- |
| 美国券商在 CRS 里吗 | 不在。IBKR 美国主体（U 开头）、嘉信国际版都不参与 |
| 那我就安全了吗 | 不。**你的港卡在 CRS 里**，年末余额和利息照报 |
| CRS 报的是盈利吗 | **不是**。存款账户报余额加利息；托管账户报卖出总额，不减成本 |
| 那两个数差多少 | 本文算例里差 **7.7 倍**——130 万 vs 17 万 |
| 税按什么算 | **当年已实现盈亏** × 20%，浮盈浮亏都不算 |
| 亏损能结转吗 | **同年可抵，跨年作废** |
| 什么时候报 | 次年 3 月 1 日 – 6 月 30 日，个税 APP |
| 港卡利息要报吗 | **要**，20%，且香港不征所以没得抵免 |
